# Gorth Support

This repository is primarily used for information, documentation, and
development of the Gorth ecosystem.

## Bugs

For bugs affecting a specific Gorth application or service, please open an
issue in the repository responsible for that project.

Include:

- A clear description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant environment information
- Logs or screenshots when applicable

## Feature Requests

Feature requests should be submitted to the repository responsible for the
affected application or platform service.

## Security

Do not use public issues for security vulnerabilities.

See [SECURITY.md](./SECURITY.md).

## General Questions

For questions about the ecosystem as a whole, use the communication channels
provided by the Gorth organization.
